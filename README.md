## 🚀 Featured Work & Deployments
* **Cloudquikportal Infrastructure:** Containerized and deployed on AWS EC2 utilizing Docker Compose, with Nginx reverse proxying and custom domain routing.
* **Automated CI/CD Architecture:** Configured Jenkins automation pipelines on Ubuntu EC2 instances with remote execution agent nodes over SSH.
* **School Management System:** Containerized a full-stack Python application utilizing Docker Compose for seamless environment portability and database management.
* **Automated Image Processing:** Developed Python automation utilizing Pillow to programmatically process and resize image assets to specific large-scale canvas dimensions.
